# ApplyScout logo kit

- `applyscout-symbol.svg`, `-reversed`, `-small`: the A mark (full colour, on dark, and the thick dot-free cut for 16 px)
- `applyscout-horizontal*.svg`, `applyscout-stacked*.svg`, `applyscout-wordmark.svg`: lockups (text is outlined)
- `variants/`: black, white, brand-mono SVGs and PNGs; favicon.ico, apple-touch-icon, icon-192/512, maskable-512, `site.webmanifest`, `head-snippet.html`
- `presentation.html` and `slides/`: the design board with mockups
- `presentation-spec.json`: the input used to build the board

Rules for use: see `../GUIDELINES.md`.
